# Security

Please report vulnerabilities privately, through
[GitHub's private vulnerability reporting](https://github.com/uranrog-01/zer0ne-Code/security/advisories/new),
not in a public issue. Include the version, the steps to reproduce it and what an attacker
could do with it.

zer0ne Code runs commands and edits files on your computer through an AI model. A model doing
something unwanted inside the permissions you granted is not by itself a vulnerability. Getting
past those permissions is: an approval, a sandbox, a command rule, or the boundary between a page
and the app.
